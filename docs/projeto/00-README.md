# Projeto - ERP EVOK AUDIO

## Estrutura dos Documentos

```text
docs/projeto/
|-- 00-README.md           <- Este indice
|-- 01-PLANO.md            <- Plano do projeto: arquitetura, stack, roadmap
|-- 02-PLANO_INDUSTRIAL.md <- Plano industrial: perfil da empresa, modulos, escala
`-- 04-USE_CASES.md        <- Casos de uso: atores e fluxos (UC-01, UC-02...)
```

Documentos de planejamento e escopo do projeto - nao sao documentacao funcional
de uma area da fabrica (essa fica em `docs/<area>/`), e sim sobre o projeto de
software em si: o que construir, em que ordem, e por que.

O SSOT vigente do projeto e o `CLAUDE.md` na raiz. O status da remediacao
pre-producao esta em `docs/AUDITORIA_PRE_PRODUCAO_2026-08-02.md`, o checklist
de go-live em `docs/GO_LIVE_G6_CHECKLIST.md` e o levantamento consolidado do
sistema em `docs/LEVANTAMENTO_ERP_2026-08-02.md`.
