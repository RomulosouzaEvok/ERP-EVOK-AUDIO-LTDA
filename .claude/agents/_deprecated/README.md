# Agentes deprecados — roster pré-CoreTriad

Os 15 agentes desta pasta formavam o roster original do ERP Evok Áudio
(2026-08-05: programador, auditor, AdmDBA, ArquitetoSoftwareAPI,
PromadorFonteEnd, webdesiner, etc.). Foram **deprecados em 2026-08-13**
pela implementação limpa do CoreTriad (aprovação APR-2026-002 em
`coretriad/governance/APPROVALS.md`) e substituídos pelos agentes
prefixados em `coretriad/`, `opuscore/`, `vericore/` e `sanacore/`.

Regra do CoreTriad: agentes deprecados são movidos para cá, nunca apagados
(skill `coretriad-materialize`, passo 5). Não referencie estes agentes em
trabalho novo. Os espelhos Codex antigos (`.codex/agents/*.toml`) descrevem
este roster e estão igualmente desatualizados — ver `GAP_ANALYSIS.md` §6.
