# SanaCore

Organização de Remediação e Engenharia Corretiva do CoreTriad.

**Ainda não tem agentes próprios** (ver `docs/coretriad/planning/GAP_ANALYSIS.md` §1 —
maior gap estrutural do CoreTriad hoje). Enquanto isso, agentes de OpusCore assumem o
papel de SanaCore, sob a mesma regra de segregação (`docs/coretriad/CORETRIAD_MASTER_SPEC.md`
§8.4). Quando agentes de SanaCore forem criados (Fase 3 de
`docs/coretriad/planning/IMPLEMENTATION_PLAN.md`), eles vivem em
`.claude/agents/sanacore/` (ou pasta equivalente) — nunca aqui.
